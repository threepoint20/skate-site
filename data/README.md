# 部落格資料儲存

這個目錄包含滑板資訊網站的部落格文章資料。

## 檔案說明

- `blog-posts.json` - 所有部落格文章的資料檔案

## 資料格式

每篇文章包含以下欄位：

```json
{
  "id": 1,
  "slug": "文章網址slug",
  "title": "文章標題",
  "content": "文章內容（支援Markdown）",
  "excerpt": "文章摘要",
  "date": "發布日期（YYYY-MM-DD）",
  "category": "文章分類",
  "readTime": "閱讀時間",
  "author": "作者姓名",
  "tags": ["標籤1", "標籤2"],
  "status": "已發布" | "草稿",
  "views": 瀏覽數
}
```

## 備份建議

- 定期備份此檔案
- 在進行大量編輯前先複製一份
- 可以直接編輯 JSON 檔案來批量修改文章

## 注意事項

- 此檔案會被 Git 版本控制
- 修改後需要重新啟動開發伺服器才會生效
- 確保 JSON 格式正確，否則會導致載入失敗
